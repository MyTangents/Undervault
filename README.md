# Sorcery: Realm of the Undervault

A first-person dungeon crawler in the spirit of the first Wizardry: a party of six, a town above, an ancient,
unexplored maze below that goes down in tall caverns and many layers. Turn-by-turn combat, permadeath, and a
chronicle of every party's story. Runs in the browser.

**Status:** demo in progress (a town menu, a few levels, combat, discoveries).

## Run it

```bash
npm install
npm run dev     # play locally
npm test        # rules tests
npm run build   # static site in dist/
```

Content is R-rated storytelling (violence, crude language, dark humour).
